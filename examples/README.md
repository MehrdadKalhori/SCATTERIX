# Real, nonidentifying example data

No simulated data or user-supplied human blood records are redistributed by this package.

You may add **verified, deidentified** reference and sample files from a documented measurement session, such as `example_conditions.json`, `sample_angular_data.csv`, and a clearly labeled workbook extract. Do not include original full spreadsheets unless you have verified that their metadata, notes and identifiers are safe for public release.

Minimum tabular fields: `sample_code`, `wavelength_nm`, `requested_angle_deg`, `estimated_motor_angle_deg`, `raw_voltage_V`, `background_voltage_V`, `acquisition_status`, `timestamp_relative_s`, `run_id`. State whether values are raw, corrected or normalized, and describe calibration and uncertainty.
